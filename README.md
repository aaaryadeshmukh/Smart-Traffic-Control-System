# Smart Traffic Control System using Spatio-Temporal GCNs

## 1. Problem Statement

Urban traffic congestion is a major global issue leading to increased travel times, fuel waste, and pollution. Traditional traffic light systems operate on fixed timers and fail to adapt to the dynamic, real-time nature of traffic flow.

This project implements an intelligent traffic management system that leverages Deep Learning and Computer Vision to analyze and predict traffic patterns. The goal is to dynamically optimize signal timings to reduce congestion and improve vehicle throughput.

## 2. System Architecture

The system is designed with a modular, end-to-end workflow, from data ingestion to real-time signal actuation in a simulated environment.

## 4. Project Overview & Methodology

The system processes real-time data to make intelligent predictions, designed with real-world deployment in mind using edge computing principles.

1.  **Data Ingestion & Preprocessing:** The system is designed to handle various data sources (GPS, Sensors, Cameras). Incoming data is normalized and cleaned to prepare it for the model.

2.  **Spatio-Temporal Modeling:** At the core of the system is a **Spatio-Temporal Graph Convolutional Network (ST-GCN)**. This architecture is uniquely suited for traffic analysis as it simultaneously learns from:
    * **Spatial Features:** The layout of the intersection (modeled as a graph) and the distribution of vehicles.
    * **Temporal Features:** The patterns of traffic flow over time.

3.  **Edge Computing & Real-Time Processing:** The model is designed to run on an edge computing device. This allows for low-latency, real-time processing of traffic data directly at the intersection, which is crucial for adaptive signal control.

4.  **Simulation Environment:** A custom simulation was built to test and validate the model's performance. The environment simulates vehicle movement and responds to the adaptive traffic light control signals generated by the STGCN model.

## 6. How to Run

To set up and run this project locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/aaaryadeshmukh/Smart-Traffic-Control-System.git](https://github.com/aaaryadeshmukh/Smart-Traffic-Control-System.git)
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Smart-Traffic-Control-System
    ```
3.  **Install the required libraries:**
    ```bash
    pip install -r requirements.txt
    ```
    *(Note: Create a `requirements.txt` file by running `pip freeze > requirements.txt` in your project's virtual environment if you haven't already.)*

4.  **Execute the main simulation script:**
    ```bash
    python main.py
    ```
